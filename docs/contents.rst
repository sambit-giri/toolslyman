Photometric IGM tomography modules
===================================

The following modules implement the photometric IGM tomography technique of
`Giri, Kakiichi, Bianco & Meerburg (2025) <https://arxiv.org/abs/2505.06350>`_;
see the :doc:`Photometric IGM tomography tutorial <examples/photometric_igm_tomography>`
for a worked example.
