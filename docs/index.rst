==========
toolslyman
==========

A python package to study lyman-alpha photons in our Universe.

The source code, issue tracker and latest updates are on GitHub at
`sambit-giri/toolslyman <https://github.com/sambit-giri/toolslyman>`_.

Package details
===============

The package provides modules to model transmission of lyman-alpha photons in cosmological volumes.

Contribute
==========

If you find any bugs or unexpected behavior in the code, please feel free to open a
`Github issue <https://github.com/sambit-giri/toolslyman/issues>`_. The issue page is
also good if you seek help or have suggestions for us. For more details, see the
:doc:`contributing` page.
